## About

I’m **N. Sivaji**, a B.Tech undergraduate exploring software engineering and turning ideas into practical projects. I’m especially interested in building technology that can help solve real problems.

- 🌊 **Currently contributing to:** [ReliefRank](https://github.com/Krish0703-irl/ReliefRank), a flood-response project that organizes SOS reports by urgency and location.
- 🧭 **What I’m doing there:** built the initial map interface ([merged PR #1](https://github.com/Krish0703-irl/ReliefRank/pull/1)); developing a FastAPI service and dynamic case pins ([PR #3](https://github.com/Krish0703-irl/ReliefRank/pull/3), open).
- 🌱 **Learning by building:** Python, APIs, maps, and ways to turn early ideas into useful software.
- 🤝 **Open to:** learning, collaborating, and constructive feedback.
